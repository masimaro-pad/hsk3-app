# HSK 3급 공부방

HSK 3급 시험 준비용 웹 앱(PWA)이에요. 아이폰·아이패드 홈 화면에 추가하면 앱처럼 전체 화면으로 열리고, 한 번 열어 두면 인터넷 없이도 쓸 수 있어요.

## 들어 있는 것
- **홈**: 14주 학습 플랜, 이번 주 할 일, 전체 진도, 복습 필요 항목
- **단어**: 주제별 568개 · 공부(병음/뜻 가리기, 발음 듣기) / 확인(플래시카드)
- **문법**: 핵심 문법 30개 카드 · 60문제
- **문장 배열**: 쓰기 1부분 대비 44문제
- **양사**: 26개 · 52문제
- **접속사**: 13개 · 26문제
- **상황별 표현**: 9가지 상황 · 72문장 (발음 듣기, 중국어로 말하기 확인)

## 설치 방법 (아이폰·아이패드)
1. 사파리로 앱 주소를 열어요.
2. 공유 버튼(□↑) → **홈 화면에 추가**
3. 홈 화면 아이콘으로 열어요.

공부 기록은 각자의 기기(그 브라우저/홈 화면 앱)에만 저장돼요. 서버로 보내지 않아요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (데이터 포함) |
| `manifest.json` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 지원. 내용을 바꾸면 `VERSION`을 올려요 |
| `icons/` | 홈 화면 아이콘 |

## 배포
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`
